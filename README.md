# Bike Sales Analysis

## Project Overview
An Excel-based analysis of bike sales data designed to identify
sales trends and customer-related patterns through data cleaning,
PivotTables, PivotCharts, and an interactive dashboard.

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Data Cleaning
- Data Visualization

## Analysis
- Cleaned and prepared the raw dataset for analysis.
- Created PivotTables and PivotCharts to analyze sales data.
- Developed an interactive Excel dashboard.
- Derived insights from sales trends and customer dimensions.
